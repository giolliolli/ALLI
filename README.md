# ALLI — Handcrafted Crochet Atelier

Artisanal, one-of-a-kind hand-crocheted wearable art conceived by Alice Marchi.
Designed between the tailored restraint of Milan and the coastal sea-light of Sydney.

- **Stack:** React 19, Vite, Tailwind CSS
- **Design Inspiration:** Milne Watson editorial composition
- **Palette:** Signature ALLI Lacca Red (`#963838`), Woven Ecru, Sand Raffia, Riviera Ink

## Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
